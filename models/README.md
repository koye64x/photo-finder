# models

ML-модели, общие для всех платформ (см. `docs/technical-design.md`).

Пока пуст. Планируется:

| Файл | Назначение | Источник и лицензия |
| --- | --- | --- |
| `yunet.onnx` | Детекция лиц + 5 ключевых точек | указать при добавлении |
| `auraface.onnx` | Эмбеддинги лиц | указать при добавлении |

Правила:
- Модели лежат в репозитории (Git LFS) и не скачиваются при сборке или в рантайме: приложение работает без сети.
- Для каждой модели указать источник, версию, лицензию и SHA-256.
- Замена модели меняет векторы и пороги, поэтому это отдельный PR с результатами теста точности до и после.
