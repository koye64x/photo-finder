# Описание идеи: приложение «Фото по лицу» для мероприятий

Nov 21, 2026 · @Yermek

Мобильное приложение для планшетов и смартфонов: человек смотрит в фронтальную камеру, видит все фото с собой с мероприятия, выбирает понравившиеся и печатает их на месте.

## Назначение

Приложение определяет одного или нескольких смотрящих на экран, находит фото с ними среди снимков мероприятия, показывает их для выбора и формирует список на печать для каждого. Мероприятия: свадьбы, юбилеи, дни рождения, тои, выпускные, корпоративы, конференции.

## Порядок работы

1. Создаётся мероприятие, для него выбирается внешний носитель (карта памяти или USB).
2. На носитель по ходу мероприятия добавляются новые снимки; приложение само их обрабатывает.
3. Пользователь нажимает «Найти мои фото» и смотрит в камеру. Перед камерой может быть несколько человек.
4. Приложение показывает фото каждого и общие фото: мозаика, слайд-шоу или по одному.
5. Пользователь отмечает фото и печатает их или забирает на телефон по QR-коду.
6. После «Готово» приложение забывает лицо пользователя.
7. По окончании мероприятия все данные о лицах удаляются; фото остаются на носителе.

## Функции

- Определение одного или нескольких смотрящих по фронтальной камере
- Поиск фото с этими людьми среди снимков мероприятия
- Просмотр: мозаика, слайд-шоу, по одному с пролистыванием
- Список выбранных фото на каждого, вкладка «Вместе» для общих фото
- Печать на подключённый принтер, лимит печати на человека
- Передача копий на телефон по QR-коду без интернета
- Завершение мероприятия с удалением данных о лицах
- Режим согласия: экран подтверждения перед включением камеры (выключен по умолчанию)

## Общие требования

- Работает полностью без интернета и без сервера.
- Фото и данные о лицах хранятся только на внешнем носителе, не передаются никуда.
- Данные о лице пользователя удаляются после его сессии, данные о лицах на фото — после мероприятия.
- Платформы: сначала Android, затем iOS с минимальными затратами на перенос.
- Работа на средних планшетах и смартфонах.
